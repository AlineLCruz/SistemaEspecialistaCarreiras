🤖 Sistema Especialista — Análise de Perfil em TI
Sistema especialista desenvolvido na ferramenta Expert SINTA, com o objetivo de orientar estudantes e profissionais em transição de carreira na identificação da área de Tecnologia da Informação mais compatível com seu perfil.

📋 Sobre o projeto
A partir de 20 perguntas sobre interesses, habilidades e preferências do usuário, o sistema aplica 15 regras de produção com encadeamento lógico em 3 camadas para chegar a uma das seguintes conclusões:

💻 Desenvolvimento de Software (Front-end / Mobile)	Desenvolvedor Front-end, Mobile, QA
📊 Ciência de Dados e Inteligência Artificial	Cientista de Dados, Analista de Dados, Engenheiro de ML
🔐 Cibersegurança e Infraestrutura / DevOps	Engenheiro de Segurança, DevOps, Cloud, Gestor de TI

⚙️ Estrutura do sistema
Camada 1 — Aptidões identificadas (R01 a R08)
Avalia as respostas do usuário e identifica aptidões em áreas como Front-end, Back-end, Segurança, Dados/IA, DevOps, Mobile, Qualidade e Gestão.

Camada 2 — Combinação em perfis (R09 a R12)
Cruza as aptidões identificadas para formar perfis mais específicos como DESENVOLVEDOR_FRONTEND_MOBILE, CIENTISTA_DE_DADOS, entre outros.

Camada 3 — Conclusão (R13 a R15)
Define a área de TI recomendada com base nos perfis e aptidões mapeados.
